## D1T1

### 题意

给定 $n$ 个 $s_i$ 和 $m$ 个 $t_j$，其中 $s_i$ 和 $t_j$ 是字符串。

构建一个新的字符串序列 $p$，其中 $p_{(i-1)\times m+j}=s_i+t_j$，$'+'$ 表示拼接。

定义 $f(i,j)$ 表示 $p_i$ 在 $p_j$ 中的出现次数，求 $\sum\limits_{i=1}^{n\times m}\sum\limits_{j=1}^{n\times m}f(i,j) $。

$1\leq n,m\leq 10^5,1\leq \sum{|s_i|},\sum{|t_j|}\leq 10^6$。

### sol

令 $s_x+t_y=p_j$，考虑两种情况：

- $p_i$ 在 $s_x$ 或 $t_y$ 里面。

- $p_i$ 被切成两块，一块是 $s_x$ 的后缀，另一块是 $t_y$ 的前缀。

考虑第一种情况咋做，ACAM 在 $s_x$ 里做多模匹配 $s_i$，对于每个 $s_x$ 里 $[1,k]$ 的前缀，我们能求出以 $k$ 为右端点能匹配出多少个 $s_i$。然后倒着匹配 $t_i$，对每个后缀的左端点算能匹配多少 $t_i$。最后对于相邻的 $k,k+1$ 合并 $s,t$ 的答案即可。$t_y$ 是同理的。

第二种情况呢？我们考虑 $s_i$ 全掉到了 $s_x$ 里的情况，因为其他情况都是同理可解决的。考虑 $t_i$ 的断点在 $t_{i,o}$ 处（$o$ 在 $s_x$ 中），用 ACAM 找到前缀能匹配上 $t_i$ 的后一半的 $t_y$ 数量。再用哈希表找到后缀能匹配上 $t_i$ 的前一半的 $s_x$，求第一种情况中的“$\mathrm{len \ of\ } s_x-o$ 为右端点能匹配出多少个 $s_i$”之和，就做完了。

复杂度 $O(|\Sigma|\times\sum|s|)$。

## D2T1

### 题意

给定 $n$ 个字符集为 $0\sim9$ 的字符串，定义一次操作 $(a,x,b,y)$ 为交换第 $a$ 个字符串的第 $x$ 个字符和第 $b$ 个字符串的第 $y$ 个字符，需要保证 $(a,x)\neq (b,y)$。

一共将执行 $k$ 次操作，每次操作从所有的合法操作中随机等概率选取。进行完所有操作后，将所有字符串视为十进制数，随后将他们相乘，乘积即为最后的结果，求结果的期望对 $10^9+7$ 取模。

$1\leq n\leq 100,1\leq m\leq 10^7,0\leq k\leq 10^9$。其中 $m$ 表示所有字符串的长度之和。

### sol

这个式子很好拆贡献，我们就考虑 $n$ 个数上各选一个数位的最终乘积期望，这里要乘上这些位置的位权乘积（就是形如 $10^x$ 这种）。钦定这些数位最终会填上初始在哪些位置上的数字，计算这些概率。

考虑 $h(i,j)$ 表示做了 $i$ 次操作，有 $j$ 个位置上填对了数。发现这样子好像计数不了，因为有可能一次还原两个数位，所以直接不钦定初始和最终的集合是如何映射的，只需要考虑集合相同就行了，换言之就是可以乱序填，反正不影响答案。然后 $h(i,j)$ 可以矩阵快速幂求。

然后我们要求某一行里选 $k$ 个点的位权乘积乘数字乘积，注意到数位值域大小是 $10$，可以直接对于一行枚举数位，做背包即可。

最后再把每一行的信息合并起来，也是一个背包，分类讨论几种情况即可，复杂度 $O(n^4+n^3\log k)$。

```cpp

#include <bits/stdc++.h>
using namespace std;
#define rep(i, x, y) for (int i = (x); i <= (y); i++)
#define per(i, x, y) for (int i = (x); i >= (y); i--)
#define int long long
constexpr int N = 105, maxn = 1e7 + 5, mod = 1e9 + 7;
int n, K, len[N], fac[maxn], ifac[maxn], inv[maxn], f[N][N][3], cnt[N][10], sum[N][10]; string s[N];
int g[N][N], ng[N][N];
struct mat { int c[N][N]; } bs, rs;
mat mul(mat x, mat y) {
    mat res; memset(res.c, 0, sizeof res.c);
    rep (k, 0, n) rep (i, 0, n) rep (j, 0, n)
        (res.c[i][j] += x.c[i][k] * y.c[k][j]) %= mod;
    return res;
}
int C(int x, int y) {
    if (x < y || x < 0 || y < 0) return 0;
    return fac[x] * ifac[y] % mod * ifac[x - y] % mod;
}
signed main() {
    ios::sync_with_stdio(false), cin.tie(0), cout.tie(0);
    cin >> n >> K;
    int slen = 0;
    rep (i, 1, n) {
        cin >> s[i], len[i] = s[i].size(), s[i] = '*' + s[i];
        int w = 1;
        per (j, len[i], 1) {
            cnt[i][s[i][j] - '0']++;
            (sum[i][s[i][j] - '0'] += w) %= mod;
            (w *= 10) %= mod; 
        }
        slen += len[i];
    }
    fac[0] = fac[1] = ifac[0] = ifac[1] = inv[1] = 1;
    rep (i, 2, maxn - 1) {
        fac[i] = fac[i - 1] * i % mod;
        inv[i] = (mod - mod / i) * inv[mod % i] % mod;
        ifac[i] = ifac[i - 1] * inv[i] % mod;
    }
    int C2 = slen * (slen - 1) % mod * inv[2] % mod;
    rep (i, 0, n) {
        int cnt = 0;
        if (i < n) {
            bs.c[i][i + 1] = (n - i) * (slen - n - i) % mod;
            cnt += bs.c[i][i + 1];
        }
        if (i > 0) {
            bs.c[i][i - 1] = i * i % mod;
            cnt += bs.c[i][i - 1];
        }
        bs.c[i][i] = (C2 - cnt % mod + mod) % mod;
        rs.c[i][i] = 1;
    }
    while (K) {
        if (K & 1) rs = mul(rs, bs);
        bs = mul(bs, bs), K >>= 1;
    }
    rep (i, 1, n) {
        f[i][0][0] = 1;
        rep (bit, 0, 9) per (k, n + 1, 0) {
            int mu = 1, mmu = 1;
            rep (j, 1, min(cnt[i][bit], n + 1 - k)) {
                (mu *= bit) %= mod;
                rep (o, 0, 2) (f[i][j + k][o] += f[i][k][o] * C(cnt[i][bit], j) % mod * mu) %= mod;
                (f[i][j + k][1] += f[i][k][0] * C(cnt[i][bit] - 1, j - 1) % mod * mmu % mod * sum[i][bit]) %= mod;
                (f[i][j + k][2] += f[i][k][0] * C(cnt[i][bit] - 1, j - 1) % mod * mu % mod * sum[i][bit]) %= mod;
                (mmu *= bit) %= mod;
            }
        }
        // rep (k, 0, n) if (f[i][k][2]) cout << i << ' ' << k << ' ' << f[i][k][2] << endl;
    }
    g[0][0] = 1;
    rep (i, 1, n) {
        memset(ng, 0, sizeof ng);
        rep (j, 0, n) rep (k, 0, n) if (g[j][k]) {
            rep (t, 0, n - j) {
                (ng[j + t][k] += g[j][k] * f[i][t + 1][1]) %= mod;
                if (t >= 1) (ng[j + t][k + 1] += g[j][k] * f[i][t][2]) %= mod;
            }
        }
        memcpy(g, ng, sizeof g);
    }
    int ans = 0;
    rep (i, 0, n) {
        (ans += g[n][i] * rs.c[n - i][0]) %= mod;
    }
    cout << ans;
    return 0;
}
```
